# 播客日常工作流程

## 目录结构

```
聊效显著/
├── 录音/
│   ├── MM_DD_YYYY/          # 每期录音文件夹，按日期命名（如 03_08_2026）
│   │   ├── hyt/             # 嘉宾录音及素材
│   │   ├── lyh/
│   │   ├── nb/
│   │   ├── wpc/
│   │   └── 工程文件/        # Adobe Audition 工程文件（.sesx）
│   └── 模板_MM_DD_YYYY/     # 新建期数时复制此模板
└── 文档/
    ├── 工作流程.md
    ├── 录制须知.md
    └── 聊效显著.md
```

---

## 文件命名规范

| 类型 | 命名格式 | 示例 |
|------|---------|------|
| 期数文件夹 | `MM_DD_YYYY` | `03_08_2026` |
| 分支名 | `ep/MM-DD-YYYY` | `ep/03-08-2026` |
| 录音文件 | `主题_嘉宾缩写.m4a` | `音乐与人生_hyt.m4a` |

---

## 注意事项

- 有版权的音乐文件（.ncm、.mp3、嘉宾分享的歌曲）**不上传**，已在 `.gitignore` 中排除
- 文件夹命名只用下划线，不用冒号或空格（跨平台兼容）

---

## Sprint Captain 工作流

> **每期由 Sprint Captain 负责创建分支和初始化目录结构。**

```bash
# 1. 切换到最新的 main
git checkout main
git pull

# 2. 创建新一期的分支
git checkout -b ep/MM-DD-YYYY

# 3. 复制模板文件夹，重命名为当期日期
cp -r 录音/模板_MM_DD_YYYY 录音/MM_DD_YYYY

# 4. 提交初始结构并推送
git add 录音/MM_DD_YYYY/
git commit -m "Init episode MM/DD/YYYY"
git push -u origin ep/MM-DD-YYYY
```

---

## 组员工作流

> **各组员在对应期数的分支下，将素材放入自己的文件夹后 push。**

```bash
# 1. 拉取并切换到当期分支
git fetch origin
git checkout ep/MM-DD-YYYY

# 2. 将录音、图片等素材放入 录音/MM_DD_YYYY/自己的缩写文件夹/

# 3. 提交并推送
git add 录音/MM_DD_YYYY/自己的缩写/
git commit -m "Add [自己的名字] materials for MM/DD/YYYY"
git push
```

---

## 收尾（所有素材齐全后）

由 Sprint Captain 发起 Pull Request，将 `ep/MM-DD-YYYY` 合并回 `main`。
